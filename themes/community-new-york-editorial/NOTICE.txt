This package contains only declarative JSON, static font data and license notices. The application and migration tool do not execute original React/CSS; separate, isolated reference QA renders the pinned upstream implementation with public synthetic data and local pinned fonts. No remote image or font requests occur while rendering this adaptation. Resume JSON remains untouched. This is an adaptation, not a pixel-identical rendering. Native GUI and Microsoft Word acceptance are separate checks.

Preservation and exact differences
The name retains its 0.5px tracking and section headings retain uppercase plus 1px tracking. Independent roles preserve the 14pt/400 real italic label and 12pt/1.6 summary. Work/volunteer positions, italic companies, education institutions/degrees, award/certificate titles and italic awarding bodies now use separate, independently styled header rows. Shared prose uses the source 11pt/1.5 role. Publication mixed inline styles and hanging indents, gray award rails, finer field/context colors and spacing, and fixed-width skill labels are not reproduced. Shared-role colors are preserved as described below. The header bottom rule uses a 0.7pt stroke instead of 0.75pt; section rules use the renderer's 1.2pt stroke instead of 1.5pt. The source prioritizes education and publications; Resume One retains the input module order. Print margins combine the source 0.75in page margin and 30px layout padding. Original Merriweather normal 400/700 and italic 400 outlines and metrics are preserved at the recorded static axes. These visible differences block high-fidelity acceptance; successful export or this notice is not a passing result.

The source display titles Professional Experience, Service & Leadership, Awards & Honors, Research Projects and Research Interests are now retained. Other modules use standard labels. Module IDs, field semantics and input order remain unchanged. Optional portraits, web hover styles and source-specific metadata overrides are not reproduced. Explicit role colors retain original RGB values; semantic palette fallbacks and application chrome still receive readability correction. Chinese and unsupported glyphs use the application's explicit Noto fallback. Source CSS pixel sizes are converted at 0.75pt per px. Editable DOCX reflows independently and is not visually certified by this package.

does not implement all Intl/timestamp behavior or change content validation.
Raw award/certificate dates and plain-text/Markdown periods remain untouched.
The inner 10pt glyph style does not yet reproduce the outer 11pt CSS strut.

Inherited line-height and project/reference update (2026-10-31): Name and
SectionTitle retain the source's inherited 1.6 line-height, not the previous
1.2/1.3 approximations. Project and reference names use independent 13pt/1.6
header rows. Projects no longer append range dates/other metadata omitted by
the source's Research Projects block; all source data and TXT/Markdown output
remain unchanged. No claim of matching flow-box baselines, spacing, pagination
or high-fidelity acceptance follows from these role-level corrections.
