Matching choices and their limits
The primary single-column literary composition, centered identity/contact,
summary after the header divider, Merriweather as the first-choice family,
regular-weight name/section headings and bold entry titles are retained.
Source CSS px are converted at 0.75pt/px: body 17px -> 12.75pt with 1.75 leading;
name 38px -> 28.5pt/400; section titles 22px -> 16.5pt/400; work/volunteer
titles 19px -> 14.25pt/700; contact/date 15px -> 11.25pt/400. Inherited 1.75
leading is retained for these roles. Independent label typography now matches
16px -> 12pt, inherited 1.75 leading and the source's true 300 italic face.
Independent summary typography matches
18px -> 13.5pt and 1.8 leading. The newly supported trackingEm preserves name
0.5px/38px = 0.013157894736842105em (0.375pt), label 0.3px/16px = 0.01875em
(0.225pt), and section headings 1px/22px = 0.045454545454545456em (0.75pt).
Serif normal 400/700 and italic 300 are the original requested faces used by
the current roles. No textTransform is applied: the source transforms only skill names,
and there is no separate skill-name role. sideDate is not declared because
the source uses inline dates; it applies only to independently side-set dates.
Colors preserve #fefdfb paper/canvas, #2f2f2f primary text, #5a5a5a secondary
text and #d4d0c8 borders. Section gap 45px becomes 11.90625mm. A4 margins
29.63mm vertical and 26.99mm horizontal approximate the source print @page
0.75in plus Layout padding 40px vertical/30px horizontal, rounded to 0.01mm.

Enumerated fidelity blockers and intentional differences
1. Summary uses 18px/1.8/#3a3a3a, text-indent:2em, and a floating first letter
   at 2.5em/0.85 with 0.05em 0.1em 0 0 margins. Independent summary size/leading
   now match 13.5pt/1.8 and exact #3a3a3a. v2 still has no first-line indent
   or drop-cap construct. Candidate retains the source text color but no cap or indent. This
   remains a significant literary loss.
2. StyledSectionTitle is centered with letter-spacing:1px, padding-bottom:12px
   and margin-bottom:25px. Section-title centering and tracking now match;
   v2 still has no configurable heading padding/margin. Candidate headings
   retain renderer vertical geometry. Name and label tracking also match. SkillName
   1px tracking still cannot be scoped separately from other item titles.
3. Label is 16px/300 italic; company and degree/publisher/issuer lines are
   16px italic. Independent label size/leading/tracking and real 300 italic
   now match. Separate company and degree/publisher/issuer roles remain
   unavailable. Label color now preserves #5a5a5a; other metadata still use
   shared body/meta styles. Company/publisher italic 400 is not
   incorrectly substituted into all metadata.
4. WorkSummary is 17px/1.8/#3a3a3a and justified; Highlights are 16px/1.8 with
   em-dash bullets, 25px left margin, 12px padding and 10px item margins.
   v2 has no justification or per-paragraph/list typography and spacing;
   candidate uses shared body text and renderer bullet/indent semantics.
5. Skills use separate 2px #d4d0c8 left rails with 20px padding, 20px inter-item
   gaps, 16px/700 uppercase names and dot-joined 16px/1.7 secondary keywords.
   v2 supports textTransform per shared typography role, but still lacks skill
   rails and a skill-name or per-section type role. Applying uppercase to all
   item titles would incorrectly alter work, education and project titles.
   Candidate uses stack. Timeline is limited to temporal modules; chips/cards
   would introduce a different visual structure and are not substitutes.
6. Languages and interests use local equal-width two-column grids with 20px
   gaps, collapsing at 640px. v2 sidebars affect document regions, not local
   section grids. Candidate uses full-width compact rows; no false sidebar
   substitute or responsive breakpoint behavior is claimed.
7. Institution, project, award, certificate, publication and reference titles
   are 18px/700 (13.5pt), skills/compact labels 16px/700 (12pt). A single v2
   itemTitle cannot express these together with 19px work titles. Candidate
   preserves the work-title hierarchy using shared 14.25pt/700 elsewhere.
8. Source date text is #7a7a7a with oldstyle-nums; company dates have a preceding
   #d4d0c8 bullet with 12px spacing. v2 has one muted token, no OpenType numeric
   feature or styled separator. Candidate uses #5a5a5a metadata and standard
   inline date semantics. sideDate does not apply to inline metadata, so using
   it would not solve this and changing the source's date placement would lose
   fidelity. Contact text also follows the shared #5a5a5a meta role instead of
   the source's #2f2f2f links. #3a3a3a prose cannot have a separate color role.
9. Source header has margin-bottom:50px, padding-bottom:30px, 1px border;
   name margin-bottom:12px, label margin-bottom:20px, contacts margin-top:20px
   and flex gap:16px; Summary margin-top:40px. Item margins vary: work 35px,
   other entries 30px, work header 10px, title 6px, prose 15px. v2 cannot set
   these individual values. Stack/compact use fixed renderer spacing. Source
   rules 1px/0.75pt become 0.7pt header and 0.6pt section rules. Contact links
   lose their CSS bottom border and hover transition; renderer link semantics
   apply instead. Footer/page numbering is renderer-owned.
10. Source screen max-width:680px with 60px/50px padding and responsive 768px
    padding change cannot coexist with fixed A4 geometry. Candidate targets
    approximate print content width. Source print changes paper to white;
    a single v2 paper token cannot switch per media, so warm #fefdfb remains
    in PDF/DOCX as well. The original screen/print distinction is not retained.
11. Source fixed order is work, publications, skills, education, projects,
    volunteer, awards, certificates, languages, interests, references. Resume
    One preserves input module order. Localized standard labels and field
    formatting replace source labels such as "Skills & Expertise", "Awards &
    Recognition", "Published by", "Awarded by", "Issued by", quoted references,
    missing-value em dashes and literal "in" in degrees. The shared work title
    merges position and employer into one bold line; the source places the
    employer with dates on a separate italic line. Education likewise merges
    degree/area/institution instead of a separate institution and degree line.
    These are significant hierarchy differences. Other standard fields may
    appear through the shared renderer even where this React omits them.
12. Chinese and glyphs outside Merriweather use the application's explicit
    fallback. Font rasterization, browser versus native line metrics and
    pagination may differ. Editable DOCX rounds sizes to half-points and
    character spacing to 1/20pt, so name 0.375pt and label 0.225pt tracking
    cannot be exact in DOCX. It reflows in its reader; Word and native GUI
    checks have not been completed.

These missing spec/renderer capabilities block near-100% visual acceptance.
