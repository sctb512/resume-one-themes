The original React/CSS was inspected as text and was not executed. This package contains only declarative JSON, static font data and license notices. No remote image or font requests occur while rendering. Resume JSON remains untouched. This is an adaptation, not a pixel-identical rendering. Native GUI and Microsoft Word acceptance are separate checks.

Preservation and exact differences
Jost is the original first-choice family; Red Hat Display is a source fallback, not the primary typography. Print paper is white as specified by the print override. Name and section headings retain uppercase transformation and the source tracking (0.5px and 3px); item headings retain 0.5px tracking. Independent label, summary and sideDate roles preserve the 13px/400 uppercase tagline with 2px tracking, 15px/300 summary at 1.8 leading, and 13px/300 dates with 0.5px tracking. The masthead rule uses 0.7pt instead of 1.5pt; inter-item keylines and em-dash list markers are unavailable. Skill/language/interest cards retain individual frames but use full-width stacking instead of auto-fill grids; 2px corner rounding is omitted. Entry position/company grouping and its subline typography are still merged by the shared semantic renderer. Shared-role colors are preserved as described below; finer field/context colors and per-element spacing are not yet reproduced. Print margins combine 0.5in page margin with 40px layout padding. These remaining visible differences block the near-100-percent fidelity gate; successful rendering and this disclosure are not acceptance.

All modules retain Resume One's localized standard labels, field semantics and input order. Optional portraits, web hover styles and source-specific metadata overrides are not reproduced. Explicit role colors retain original RGB values; semantic palette fallbacks and application chrome still receive readability correction. Chinese and unsupported glyphs use the application's explicit Noto fallback. Source CSS pixel sizes are converted at 0.75pt per px. Editable DOCX reflows independently and is not visually certified by this package.

Shared-role color update (2026-10-30): source Name/Position titles #111827,
Label #6b7280, Summary #374151, SectionTitle/shared prose #4b5563 and independent
side dates #9ca3af are now explicit typography colors. The light source date
color is retained exactly instead of being darkened by the global interface
contrast rule. Body-derived item titles have their own explicit color, so
changing prose does not recolor them. Contact/metadata and position/company
fragments still share roles where the source distinguishes them, and local
grid/spacing differences remain. These partial corrections are not final
high-fidelity acceptance. Personal palette changes remain separate overrides.
